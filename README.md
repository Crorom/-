# 질주 본능

위에서 내려다보는 3차선 도로를 달리며, 다가오는 차를 피하고 아슬아슬하게 스칠수록 더 빨라지는 HTML5 무한 주행 게임입니다. 브라우저에서 바로 플레이할 수 있고, 같은 게임을 WebView로 감싼 안드로이드 앱도 이 저장소에 들어 있습니다.

한 판은 보통 1~5분입니다. 가속과 정지는 없고, 플레이어가 하는 일은 차선을 바꾸는 것뿐입니다.

## 핵심

핵심 경험은 **아슬아슬한 곡예운전**입니다. 차와 부딪히면 바로 끝나고, 차 앞을 스치듯 차선을 바꾸면 Near-Miss가 되어 속도가 올라갑니다.

- **3차선.** 플레이어는 화면 아래에 고정되고, 도로와 장애물 차가 위에서 아래로 내려옵니다. 한 번 입력하면 인접 차선으로 한 칸 이동합니다.
- **항상 빈 차선이 있습니다.** 같은 줄에 차가 나와도 세 차선을 동시에 막지 않습니다.
- **Near-Miss.** 장애물 차의 앞부분 판정 안에서 차선을 바꾸면 발동합니다. 속도가 1.2배씩 오르고, 최대 2.0배까지 유지됩니다. 그냥 지나가는 것만으로는 발동하지 않습니다.
- **Speed Burst.** 속도가 최대에 닿으면 위쪽 입력으로 3초간 질주할 수 있습니다. 이때 속도는 기본의 4배이고, 충돌해도 게임 오버가 되지 않으며, 통과하는 차마다 100점이 들어옵니다. 끝나면 속도는 다시 1.0배로 돌아갑니다.
- **점수.** 일반 통과는 속도 단계에 따라 1~5점, Near-Miss는 5~25점입니다. 최고 점수는 브라우저 `localStorage`에 남습니다.
- **사운드.** 속도가 오르면 BGM 재생 속도도 함께 올라갑니다. Near-Miss와 게임 오버에는 효과음이 겹칩니다.

## 이 저장소에 들어 있는 것

| 경로 | 내용 |
|------|------|
| `index.html` | 메인 메뉴. 자동차 설명, 세계관, 게임 시작 |
| `game.html`, `game.js`, `styles.css` | 실제 게임. Canvas 렌더링과 입력, 판정, HUD, 사운드 |
| `cars.html` | 세계관용 차량 소개 페이지 |
| `world.html` | 배경 도시 네온 시티 이야기 |
| `car_image/` | 탑뷰 차량 이미지. 게임은 `car_image_fix`를 사용 |
| `music/` | `BGM_1.mp3`, Near-Miss·게임 오버 효과음 |
| `GDD_01` ~ `GDD_04` | 기획서. 핵심 경험, 게임플레이, Speed Burst·점수, 사운드 |
| `JilJuBonNeung_Android/` | 같은 웹 게임을 담은 안드로이드 WebView 앱 |
| `.github/workflows/` | GitHub Pages 배포, 안드로이드 APK 빌드 |

루트의 영상·음원 조각과 `곡예운전 자동차모음.psd`는 연출·원본 작업 파일이며, 게임 실행에는 쓰이지 않습니다.

## 조작

| 동작 | PC | 모바일 |
|------|----|--------|
| 왼쪽 차선 | `←` 또는 `A`, 화면 ◀ | 왼쪽 슬라이드 |
| 오른쪽 차선 | `→` 또는 `D`, 화면 ▶ | 오른쪽 슬라이드 |
| Speed Burst | `W`, `↑`, 또는 속도 게이지 | 위쪽 슬라이드 또는 게이지 |

가장 바깥 차선에서 벽 쪽으로는 이동하지 않습니다. 오른쪽 위 ⚙에서 일시정지, 포기, BGM·효과음 음량을 조절할 수 있습니다.

## 실행

웹은 별도 빌드가 없습니다. `index.html`을 브라우저로 열면 됩니다. 사운드와 일부 브라우저 정책 때문에, 로컬 서버로 여는 편이 안정적입니다.

```powershell
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 으로 접속한 뒤 **게임 시작**을 누릅니다.

안드로이드 앱은 `JilJuBonNeung_Android`를 Android Studio에서 열거나, 이 저장소를 GitHub에 올리면 Actions의 **Build Android APK**가 디버그 APK를 만듭니다. 최소 SDK는 24, 화면은 세로 고정입니다. 웹 파일을 고친 뒤에는 `app/src/main/assets/` 안의 같은 파일도 맞춰야 앱에 반영됩니다.

`main`에 웹 파일이나 이미지·음악을 푸시하면 **Deploy Web to GitHub Pages**가 게임 페이지만 배포합니다. 기획서, 안드로이드 프로젝트, 작업용 영상은 페이지에 포함되지 않습니다.
